Furniro - Furniture E-commerce Landing Page
Overview

Furniro is a modern, visually appealing furniture e-commerce landing page built using HTML and Bootstrap Icons. The page is designed to showcase products, collections, and promotional banners in an engaging way, offering users a seamless browsing experience.

This project is ideal for designers, developers, or businesses looking to create a responsive furniture website.

Features
Responsive Design: Adapts to all screen sizes using a mobile-friendly layout.
Navigation Menu: Easy-to-use menu with links to Home, Shop, About, and Contact sections.
Hero Banner: Engaging top banner with promotional text and call-to-action button.
Browse Collections: Showcase different furniture categories like Dining, Living, and Bedroom.
Product Showcase: Detailed product cards with images, prices, discounts, and options to Add to Cart, Share, Compare, or Like.
Middle Banner: Highlighted room inspirations with interactive cards.
User Gallery: Share your setups via #FurniroFurniture for community engagement.
Footer Section: Contact info, quick links, help section, and newsletter subscription form.
Icons: Uses Bootstrap Icons for search, cart, share, and social interactions.
