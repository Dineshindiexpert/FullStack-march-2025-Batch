# 🌍 Travelsy - Responsive Travel Website UI

##  Overview
Travelsy is a modern and fully responsive travel website UI built using **HTML5** and **CSS3**.  
It showcases travel destinations, hotels, events, and blogs in a clean, user-friendly interface. This project focuses on front-end design and responsiveness without any JavaScript functionality.

---

## 🚀 Features
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎨 Clean, modern UI/UX
- 🏨 Hotel showcase with cards and pricing
- 🎉 Event and party venue sections
- 📰 Latest blog/news section
- 🧑‍🤝‍🧑 Testimonials carousel
- 📬 Newsletter subscription
- ⚡ Optimized layout using Flexbox & CSS Grid

---

## 🛠 Tech Stack
- **HTML5** for structure  
- **CSS3** for styling and layout  
- **Flexbox** & **CSS Grid** for responsive layouts  
- **Media Queries** for mobile responsiveness  
- **Google Fonts** (Corinthia, Mulish, Space Grotesk)  
- **Bootstrap Icons** for icons
